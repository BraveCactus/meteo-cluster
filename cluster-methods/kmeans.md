# K-Means

Алгоритм k-means используют для группировки объектов в наборы (кластеры) на основе их схожести. В основе работы k-means лежит принцип минимизации расстояния между объектами внутри одного кластера.

## Этапы работы алгоритма K-Means:

1) **Инициализация центроидов.** Алгоритм выбирает k начальных точек, называемых центроидами. Эти точки служат временными центрами кластеров.

2) **Назначение объектов кластерам.** Каждый объект в наборе данных назначается к кластеру, центроид которого находится ближе всего. Для расчета расстояния обычно используют евклидову метрику.

3) **Обновление центроидов.** После назначения объектов кластерам вычисляют новые центроиды. Каждый центроид перемещается в среднюю точку всех объектов, принадлежащих его кластеру.

4) **Повторение.** Шаги 3 и 4 повторяют до тех пор, пока центроиды не перестанут значительно изменяться, что свидетельствует о достижении сходимости. В некоторых реализациях алгоритм также может быть завершен при достижении заданного числа итераций.

---

## Преимущества и недостатки k-means

**Преимущества**

1) Простота и быстрота реализации.

2) Эффективность при работе с большими наборами данных.

3) Возможность применения в различных областях.

**Недостатки**

1) Зависимость от выбора числа кластеров.

2) Чувствительность к начальной инициализации центроидов. Различные начальные точки могут привести к различным результатам.

3) Плохо справляется с данными, содержащими выбросы или сложные формы кластеров, например с перекрывающимися или нелинейными кластерами.

4) Не подходит для категориальных данных без предварительного преобразования.

## Приложение A. KMean++ для выбора начальных центроидов

### Описание алгоритма

Пусть у нас есть данные X (набор точек) и мы хотим найти K центров.

1. Выбираем первый центр случайно

Берем любую точку из набора данных с **равномерной вероятностью**. Назовём её **C₁**.

2. Считаем расстояния до ближайшего центра

Для каждой точки **xᵢ** в данных вычисляем **D(xᵢ)** — квадрат расстояния от этой точки до ближайшего к ней уже выбранного центра.

**Формула:**

$$
D(x_i) = \min_{c \in \text{centers}} \|x_i - c\|^2
$$

3. Выбираем следующий центр случайно (с весами)

Теперь мы выбираем новую точку с вероятностью, **пропорциональной её D(xᵢ)**.

**Вероятность для точки xᵢ стать новым центром:**

$$
P(x_i) = \frac{D(x_i)}{\sum_{j} D(x_j)}
$$

4. Повторяем действия 2 и 3

Добавляем выбранную точку в список центров и повторяем процесс до тех пор, пока не наберем **ровно K** центров.

## Приложение Б. Метод локтя

Один из самых сложных этапов алгоритма k-means — выбор оптимального числа кластеров k. Если значение k слишком маленькое, то в одном кластере могут оказаться слишком разные объекты, что ухудшит качество кластеризации. Если значение k слишком большое, кластеры могут стать слишком мелкими и специфичными, что также приведет к плохим результатам. Чтобы выбрать оптимальное число кластеров, можно использовать несколько методов, и один из самых популярных — метод локтя.

**Алгоритм метода локтя:**

1) Запускаем алгоритм k-means для разных значений k, например от 1 до 10.

2) Вычисляем внутрикластерную дисперсию для каждого значения k. Это можно сделать с помощью метрики, которая рассчитывает сумму квадратов расстояний между точками данных и центроидом их кластера.

3) Строим график: на оси X откладываем значения k, а на оси Y — соответствующие значения внутрикластерной дисперсии.

4) Ищем «локоть» на графике: это точка, где дальнейшее увеличение числа кластеров не приводит к значительному снижению внутрикластерной дисперсии.

## Приложение В. Алгорит Ллойда

## Описание алгоритма

Пусть у вас есть набор данных **X** и вы заранее выбрали число **K** (количество кластеров).

1. Инициализация

Выбираем **K** начальных центров кластеров.

*(Например алгоритм K-Means++, но можно и просто случайные точки из данных).*

2. Назначение

Для каждой точки в данных находим, какой из **K** центров находится к ней ближе всего.

Приписываем точку к этому кластеру.

3. Обновление

Для каждого получившегося кластера вычисляем его новый центр.

Новый центр — это среднее арифметическое (центроид) всех точек, которые были назначены этому кластеру.

**Формула:**

$$
\mu_k = \frac{1}{|S_k|} \sum_{x_i \in S_k} x_i
$$

Где **S_k** — это множество точек, принадлежащих **k-му** кластеру.

4. Проверка сходимости

Сравниваем новые центры с теми, что были на прошлой итерации.

Если изменение центров меньше заранее заданного порога (например, 0.0001), то алгоритм останавливается.
Иначе возвращаемся к действию 2.
